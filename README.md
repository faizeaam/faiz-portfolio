## How to Run

Open any `.html` file directly in your browser.

Example:

1. Open the project folder in VS Code
2. Right-click on any HTML file
3. Select "Open with Live Server" or open in browser

## Recommended Repo Structure

For a cleaner portfolio setup, use this structure:

- `faiz-portfolio/` -> portfolio website only
- `faiz-projects/` -> all project files together

This keeps your main portfolio clean and your project work easy to share.
